# Готель Лапка — ЛР №7

Лендинг на основі ЛР №6: HTML5, Tailwind через CDN, custom CSS та JavaScript. Нові блоки: локальна відеопрезентація, тематичне YouTube-відео, демонстраційна карта OpenStreetMap, динамічна погода Open-Meteo.

## Запуск
Відкрити `index.html` через VS Code Live Server. Для Tailwind, YouTube, карти та погоди необхідний інтернет.

## Деплой Netlify
Netlify → Add new project → Deploy manually → перетягнути папку `lab7-lapka` (не кореневий архів). Після публікації внести URL у звіт.

## Важливо
Показана на карті точка — центр Львова лише для демонстрації, не адреса готелю. Зовнішнє YouTube-відео не є відео готелю. Контактна форма відкриває чернетку листа без адресата, оскільки у вихідних матеріалах немає підтвердженого email. Вартість — навчальний розрахунок, а не підтвердження бронювання.

## Перевірки до здачі
Відкрийте DevTools → Device toolbar: 320, 375, 768, 992, 1024, 1280, 1440px. Перевірте Console, Network, Lighthouse, HTML/CSS validator, плеєри та карту. Зробіть скріншоти та впишіть фактичні результати у PDF.
