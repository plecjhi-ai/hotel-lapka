## Потрібні скріншоти
1. Форма у VS Code та її семантичний код.
2. Форма desktop 1440px, mobile 375px у Chrome DevTools.
3. Стан помилки (email/телефон), успішний стан, відкрите модальне вікно.
4. Console без JS-помилок, URL опублікованого сайту Vercel.
5. Git-коміт для ЛР №9 та Vercel Deployments після push.
