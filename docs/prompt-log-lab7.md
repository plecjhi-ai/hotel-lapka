# Промпт-паспорт лабораторної №7 — «Готель Лапка»

## Master Prompt (інженерне завдання)
Ти — Senior Frontend Developer та UI/UX Engineer. Продовжи існуючий навчальний проєкт «Готель Лапка» з ЛР №6. Мета — односторінковий адаптивний лендинг готелю для собак і котів із закликом «Розрахувати вартість». Збережи наявні кольори, шрифти, графіку, секції та розрахунок. Використовуй HTML5, Tailwind CSS, наявний custom-styles.css лише для брендових стилів, JS тільки для інтерактивності. Не вигадуй адресу, відгуки чи характеристики. Додай власне MP4, окреме тематичне відео YouTube в iframe, демонстраційну інтерактивну карту OpenStreetMap, динамічний погодний віджет Open-Meteo. Вкажи, що карта показує демонстраційне місце, а відео — стороннє. Додай alt, title, loading=lazy та адаптивні iframe. Підготуй сайт до Netlify.

## Ітераційні запити й зроблені зміни
1. **Структура:** «Збережи Header, Hero, Benefits, Rooms, Pricing, About, Reviews, FAQ, CTA, Footer; встав тематичний медіаблок до FAQ». Результат: інтегровані нові секції `#media`, `#location`.
2. **Мультимедіа:** «Додай локальне MP4 і тематичний YouTube iframe 16:9, title, lazy loading; уникни горизонтального скролу». Результат: відеокартки з адаптивними контейнерами.
3. **Точковий Pick Element:** «Працюй тільки з iframe карти, додай назву, адаптивні розміри і lazy-loading, не змінюй інші секції». Результат: iframe у контейнери без фіксованої ширини.
4. **Динамічний віджет:** «Додай поточну погоду Open-Meteo з обробкою помилок мережі, без API-ключа». Результат: кнопка оновлення, повідомлення про збої.
5. **Аудит:** «Перевір семантику, заголовки, збереження брендових кольорів, роботу калькулятора та зовнішніх ресурсів». Результат: статична перевірка; живий браузерний аудит треба виконати після розгортання.
